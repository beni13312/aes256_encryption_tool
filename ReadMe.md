# AES256 Encryption tool

This is a tool that can encrypt/decrypt files/folders with a randomly generated private key that saved as a file.

## cmake build Debug

`cmake --build /home/benjamin/Documents/Dev/build --config Debug --target all -j 12 --`

## cmake build Release

`cmake --build /home/benjamin/Documents/Dev/build --config Release --target all -j 12 --`
